In the Pair-Programming workflow, we split a task into many small coding sessions.
This is done to keep the context small.

If the current working directory contains a `PREP.md` file, read it and use the contained information as a baseline for the current session.

One iteration of this workflow will look as follows:

1. The user asks you to perform a small to medium sized task.
2. You should then perform the task.
3. The user then revies the diff generated by git. This also means, you don't need to generate any summaries or diff's yourself.

After each iteration, the user might clear the session to reduce the context size.
